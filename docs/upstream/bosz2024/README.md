# BOSZ 2024 official documentation (archived verbatim)

Verbatim copies of the upstream documentation for the BOSZ 2024 MAST
HLSP, kept here for offline reference. The files are unmodified upstream
content; every fact stellarlib relies on is re-stated (with its own
verification evidence) in `docs/data-sources.md` and the model catalog —
these files are the source of record, not the working knowledge.
